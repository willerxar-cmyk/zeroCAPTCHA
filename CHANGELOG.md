# Changelog

## 0.1.0 · 2026-11-24

- Standalone Rust release derived from the original zeroCAPTCHA proof-of-work
  engine and browser solver, with a distinct signing domain.
- Includes a browser widget with the original hand illustration and linked
  attribution, a local demo, HTTP reference and deployment guide.
- Supports an optional shared single-use store and server-timed precision
  protocol for custom integrations.
